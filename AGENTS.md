# AGENTS.md

DWM-like dynamic tiling window manager for the River Wayland compositor (implements river-window-management-v1). Written in Zig.

## Toolchain

- Requires Zig **0.16.x** exactly (`minimum_zig_version = "0.16.0"`). Installed via mise; other versions will fail.
- The LLVM/LLD backend is the **default** (`use_llvm = true`, build.zig:83-87). Do not pass `-Dllvm=false`: the self-hosted linker cannot relocate GCC 16's `.sframe` sections in crt1.o.

## Build

```sh
zig build                       # defaults to ReleaseSafe? no — default optimize is Debug; use:
zig build -Doptimize=ReleaseSafe
zig build test                  # runs all tests
zig build run                   # runs kwm (requires a running river compositor)
```

Project options (see `zig build --help`): `-Dbar` (default true), `-Dbackground` (default false), `-Dkwim` (default true), `-Dconfig=<path>`, `-Dpie`, `-Dversion-string`. When `-Dbar=true`, the lazy deps `pixman`/`fcft`/`goose` are fetched and `systray.zig` is compiled in.

## Tests

- `zig build test` runs **three** parallel test executables built from the `config`, `kwm`, and `exe` root modules (build.zig:306-330).
- Tests in a leaf file only run if that file is referenced from the module's `test {}` block. New test files must be added there — currently `src/kwm.zig:39` references `kwm/utils.zig`, `kwm/render/utils.zig`, and `kwm/systray.zig` (systray only when `-Dbar`).
- There is no per-module top-level test step; `zig build test` runs everything.

## Configuration gotchas

- `config.zon` is **gitignored** and auto-created from `config.def.zon` at build time if missing (build.zig:110-142). Only `config.def.zon` is committed; edits to a generated `config.zon` won't land in the repo.
- The config is a Zig source compiled into the binary (`config_mod` imports `default_config_mod`, which is `config.zon` passed through `src/preprocess_config.zig`). Editing the `.zon` changes types used across `src/config/`, so errors surface at compile time.
- Preprocessing directives (`// @include(file)`, `// @if/elif/else/@endif`) are evaluated at build time against hostname/env; see README "Configuration Preprocessing" and `src/config/preprocess.zig`.
- Runtime config from `$XDG_CONFIG_HOME/kwm/config.zon` (or `-c` flag) is merged over the compile-time defaults and can be reloaded with mod4+shift+r.

## Architecture

- `src/main.zig` — entrypoint: binds Wayland globals (river window-management/xkb-bindings/layer-shell v1, viewporter, fractional-scale, etc.), registers a custom panic/crash handler (`src/kwm/crash.zig`).
- Module graph: `config` and `kwm` **import each other** (build.zig:193-194). Changes to the config type surface can break either side.
- Wayland protocol XMLs live in `protocol/` (river protos, ISC licensed); client code generated at build time via zig-wayland's Scanner, so protocol updates require the matching `scanner.generate(...)` version bump in build.zig:43-55.
- Feature-conditional code uses `@import("build_options").bar_enabled` (e.g. `systray.zig`, bar rendering) — keep new bar-only code behind the same check.

## Docs

- `doc/kwm.1` is generated from `doc/kwm.1.scd` via scdoc; edit the `.scd` and regenerate (header: "Generated by scdoc").
- `config.def.zon` is the canonical reference for all features; `doc/keybindings.md` documents bindings.
